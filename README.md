# ATLAS — Computational Pharmacology Research

An independent research software project by Jorge Rodriguez exploring literature evidence, pharmacokinetic simulation, receptor-binding prediction, and model validation using AI-assisted development.

See [STATUS.md](STATUS.md) for the implementation status, measured limitations, and reproduction commands. This is research software, not a clinical tool or a source of individual treatment recommendations.
